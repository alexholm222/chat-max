# Chat MAX

Тестовое приложение чата на React с интеграцией GREEN-API для MAX.

## Стек

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Zustand
- RxJS
- Axios
- SCSS Modules
- TanStack Virtual

## Возможности

- Авторизация по `idInstance` и `apiTokenInstance`
- Проверка состояния инстанса
- Получение списка чатов
- Виртуализация списка чатов
- Отображение последних сообщений
- Открытие истории переписки
- Отправка сообщений
- Получение входящих сообщений в реальном времени
- Отображение статуса отправленных сообщений
- Отметка сообщений как прочитанных
- Поиск чата по номеру телефона
- Отображение аватаров и количества непрочитанных сообщений

## Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Переменные окружения

Создайте файл `.env`:

```env
VITE_API_BASE_URL=YOUR_API_URL
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

## Архитектура

Проект организован по принципам Feature-Sliced Design:

```text
src/
├── app/          # Инициализация приложения, роутинг, провайдеры
├── pages/        # Страницы приложения
├── widgets/      # Крупные самостоятельные блоки интерфейса
├── features/     # Пользовательские действия
├── entities/     # Бизнес-сущности
└── shared/       # Переиспользуемый код и UI
```

## Работа с API

Для запросов используется Axios.

TanStack Query используется для:

- загрузки и кеширования данных;
- мутаций;
- обновления кеша после отправки и получения сообщений;
- синхронизации данных между компонентами.
